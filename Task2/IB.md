# Задание 2. Разработка и заполнение проверочного листа для бизнес-систем

Необходимо составить проверочный лист безопасности для бизнес-систем. Для этого:
- Проанализируйте схему и описание системы. Идентифицируйте системы и изучите характер их работы с точки зрения безопасности.
- Выберите, какие разделы включить в проверочный лист, исходя из проблем и приоритетов компании. Подробно объясните свой выбор — это важная часть решения.
- Оформите проверочный лист в виде Markdown-таблицы. 

# Решение

## Выбор разделов проверочного листа

| Раздел | Приоритет обработки раздела | Описание |
| ------ | ------- | --------- |
| I. Управление доступом | 1 | Есть проблемы с доступом к партнерскому апи, требуется детальный анализ. |
| II. Безопасность данных | 1 | Планируется расширениенаправления обрабоки данных, есть очевидные проблемы синхронизации данных между системами.  |
| III. Защита инфраструктуры |  1 | Нужно проверить соответствие требованиям законодательства. |
| IV. Управление инцидентами |  2 | Для анализа недостаточно данных. В компании всего один ИБ-специалист, вероятно работа над инцидентами не организована на должном уровне.  |
| V. Специфические аспекты | 3  | Для анализа недостаточно данных. Но анализ требуется для предотвращения рисков компроментации доступа |
